# Contributing to Graphden

Thank you for your interest in contributing to Graphden!

## How to contribute

1. Fork the repository.
2. Create a feature branch from `develop` (the integration branch; `main`
   tracks releases).
3. Make your changes and add tests where appropriate.
4. Ensure all checks pass:
   - `bb lint`
   - `bb test`
5. Open a pull request against the `develop` branch.

## Contributor License Agreement (CLA)

Before we can merge your contribution, you need to agree to the Contributor License Agreement (CLA).

By opening a pull request and checking the CLA checkbox in the pull request template, you confirm that:

- you have read and understood the [CLA](./CLA.md);
- you agree to be bound by its terms for all Contributions included in that pull request.

If you do not agree to the CLA, please do not submit Contributions to this project.
