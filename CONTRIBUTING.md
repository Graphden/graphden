# Contributing to Graphden

Thank you for your interest in contributing to Graphden!

## How to contribute

1. Fork the repository.
2. Create a feature branch from `develop` (the integration branch; `main`
   tracks releases).
3. Make your changes and add tests where appropriate.
4. Ensure all checks pass:
   - `bb lint`
   - `bb test`
5. Open a pull request against the `develop` branch.

## Contributor License Agreement (CLA)

Before we can merge your contribution, you need to agree to the Contributor License Agreement (CLA).

When you open your first pull request, a bot (`CLA Assistant`) comments with
a one-sentence signing phrase. Reply to the pull request with that exact
sentence and the check turns green — once per GitHub account, recorded on
the `cla-signatures` branch. The checkbox in the pull request template is a
reminder; the bot's record is what counts, and a pull request cannot be
merged without it.

By signing you confirm that:

- you have read and understood the [CLA](./CLA.md);
- you agree to be bound by its terms for all your Contributions.

The CLA assigns copyright in your contribution to the project owner (with a
full license back to you). That is what keeps the open core relicensable
and the [package exception](./LICENSE-EXCEPTIONS.md) grantable — a DCO
would not. If you do not agree to the CLA, please do not submit
Contributions to this project.
